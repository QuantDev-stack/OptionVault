# OptionVault Documentation Directory

Welcome to the OptionVault documentation section. This directory contains detailed guides, dictionaries, and specifications for the historical options database.

## Documentation Index

1.  **[Dataset Coverage](dataset_coverage.md):** Detailed list of assets, historical range, and resolutions available.
2.  **[Data Dictionary](data_dictionary.md):** Column-by-column descriptions and data types for cash, futures, options, Greeks, and tick logs.
3.  **[Database Schema](schema.md):** ER diagrams, joins, and common SQL/DuckDB analytical queries.
4.  **[Naming Conventions](naming_conventions.md):** Explanation of NSE weekly and monthly option/future symbols.
